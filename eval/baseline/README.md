## 规矩

| 字段 | 规矩 |
|---|---|
| `order` | **从 1 开始、按作业书里出现顺序连续编号** —— 它就是和 agent 的 `R1..Rn` 对齐的键 |
| `weight` | 抄原文的分值（"30 分" / "30%" → `30`）；原文没标分值的填 `null` |
| `decomposable` | `true` = 可拆（进覆盖率分母）；`false` = 模糊（不进分母）。三条判据：① 指向具体交付物、或已列举内容/子项（A/B/C/D 小节、里程碑、清单）→ `true`，哪怕标题读起来很虚；② 没有任何交付物、只能靠主观印象打分 → `false`；③ 拿不准 → `true` |
| `label` | **自己写的一句话标签**（≤12 字）。**不要复制原文句子** |

## 不变量

- **只从「评分标准 / 成绩评定 / 考核方式 / 评分细则 / 评分表」小节标**，不从正文要求标（D-48 ④）——否则 M8 与循环口径两个分母不可比。
- **原文不入库**（D-41）：本目录只存 `order` / `weight` / `decomposable` / `label`，任何机位都不放作业书原文。agent 产物快照（含 `quote`）落在 `eval/runs/`，已 `.gitignore`。
- `weight` 加总应落在 100 附近（人工抄错会被 `report.py` 的分值校验 ⚠️ 点名）。

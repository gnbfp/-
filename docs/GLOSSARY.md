## 二、核心名词

| 名词 | 一句话 |
|---|---|
| **作业书** | 老师下发的原始任务书（文字版 PDF / Word / 纯文本；**图片和扫描件拒收**） |
| **评分点（rubric point）** | M1 从作业书抽出的可打分项（`R1`、`R2`…）。必须带**原文引用 `quote`**，用来防 LLM 编造 |
| **任务卡（task card）** | M3 拆出来的执行单元（`T1`、`T2`…），**7 个字段**，含 `rubric_refs` 溯源 |
| **「模块」** | 任务卡面向组员的**口语叫法**；数据模型里就是 `task_id`。志愿填的就是它 |
| **作业元信息** | 课程名 / 作业标题 / 交付形式 / **截止时间**；截止时间是**作业级一根线**，任务卡不设 `due_date` |
| **志愿（preference）** | 组员对 `task_id` 的排序（第一志愿、第二志愿） |
| **分配（assignment）** | 谁干哪张卡。`source` 四值：`volunteer_1` / `volunteer_2` / `auto` / `leader` |
| **提议（proposal）** | M5 的匿名代言记录，含真实身份，存 `data/proposals.json` |
| **「方向」** | 作业的**选题大方向**（不是章节、不是任务卡）。M2 在群里投票定 |
| **花名册（roster）** | 组长 + 组员（`open_id` + 显示名），群里「登记」产出，存 `data/members.json` |

## 三、机制与指标

| 名词 | 一句话 |
|---|---|
| **覆盖率三口径** | ① 循环退出：分母 = 可拆评分点，**必须 100%**；② D5 门：分母 = 人工标注点，**≥80%**；③ M8 报告值：同 ②，**不设阈值**。三者禁止混用 |
| **均衡度两套口径** | 循环内判据 `max/min ≤ 3`；M8 报告展示 `1 − (max−min)/Σ`。两个独立函数，禁止复用 |
| **自检循环 `check()`** | 生成 → 最多 2 轮代码判定 → 失败喂回重拆。**LLM 不参与判定** |
| **D5 发布门** | **9/15 周二晚**，三条全过才开始 P1；任一不过 → 冻结全部 P1 |
| **前缀精确匹配** | 指令只看开头几个字，不做自然语言理解 |
| **状态优先** | 路由顺序：先剥 @段 → 再查 `state.json` 的 `awaiting` → 最后才认前缀。裸数字靠它解释成票号 / 志愿序号 |
| **`awaiting`** | `state.json` 里的"当前在等什么"：`vote` / `preference` / `register` |
| **投票窗口** | M2 发候选时开启；某方向拿到**已投票者过半** / 超时 10 分钟 / 组长拍板，任一满足即关 |
